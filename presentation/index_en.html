Challenge #544

AES Distrace

You have the opportunity to execute this binary which performs AES-128-ECB encryption on a random input, while observing the value of a register at a fixed address throughout the computation.

Note: The path /app/ in the provided Python file (aes-distrace.py) needs to be adapted to your environment to run the challenge locally.

File(s) to examine:

  • aes-distrace.c
  • aes-distrace
  • aes-distrace.py
  • libexeclog.so
  • qemu-x86_64
