Challenge #544

AES Distrace

Hai la possibilità di eseguire questo binario che esegue una cifratura AES-128-ECB su un input casuale, osservando contemporaneamente il valore di un registro a un indirizzo fisso per tutta la durata del calcolo.

Nota: Il percorso /app/ nel file Python fornito (aes-distrace.py) deve essere adattato al tuo ambiente per eseguire la sfida localmente.

File da analizzare:

  • aes-distrace.c
  • aes-distrace
  • aes-distrace.py
  • libexeclog.so
  • qemu-x86_64
